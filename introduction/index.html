Introduction to ScaffCover

The world's only modular scaffold containment system.

Designed to integrate with all scaffolding systems, ScaffCover creates a clean, continuous connection across the structure, improving performance, consistency and finish. With a wide range of panel options, it provides a solution for every scaffold containment requirement.

This page brings together everything you need to understand how ScaffCover works and how it can be applied to your project:

  • Brochures for the system and each Guard panel
  • Technical and engineering documentation
  • Test reports and specification data sheets
  • Installation videos and an interactive 3D model
