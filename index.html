The TRAKTEC system

A containment system. Designed to work as one.

A system is more than a collection of components. Each part has a defined role, each connection is designed to work with the next, and together they solve a complete task. In containment, that means addressing how the panel is fitted, held and changed — not leaving those connections to be worked out separately on every job.

ScaffCover brings those decisions into one coordinated platform. Connectors attach the TRAKTEC track to the scaffold. Guides introduce the panel's reinforced edge into the track. The Guard Range provides different containment options on that common foundation. Change the panel and configuration to suit the application, while retaining the way the system connects.

One coordinated system. A wider range of containment possibilities.

The four pillars of ScaffCover

Track, Core, Connect and Guard each have a defined role. Together, they form one coordinated containment system.

TRACK — The panel pathway

TRAKTEC aluminium track receives and retains the panel's reinforced keder edge. Track and suspension bars provide the framework for positioning panels within the system.

CORE — The scaffold connection

Scaffold connectors, clamps and stoppers form the supporting hardware. Core connects and positions the track on the scaffold, with components selected to suit the scaffold type and configuration.

CONNECT — Joining and installation

Track joiners align adjoining track sections, while panel guides introduce the reinforced panel edge into the track. Connect supports continuity and controlled panel installation.

GUARD — Containment for the application

The Guard Range provides purpose-built panels for different containment requirements, including airflow, weather protection, printed presentation and industrial work. Each uses the system's common track interface.

Engineering

Designed. Tested. Proven.

Independent testing, engineered connections and documented performance. ScaffCover brings the track, connectors and Guard panels together as one coordinated containment system.

Engineered to work together.

The reinforced panel edge engages continuously with the TRAKTEC track, distributing load along the connection. Laboratory testing evaluates panel retention, connection strength and the performance of the assembled system.

12.8 kN/m

Panel-to-track connection

All Guard panels use the same panel-to-track connection. Independent pull-out testing recorded a mean breaking strength of 12.8 kN per metre of engaged panel edge.

9.7×

Stronger per metre

The shared panel-to-track connection gives every Guard panel the same 9.7× connection-strength comparison: 12.8 kN/m against cable ties at 600 mm centres (1.32 kN/m).

3.5 kN

ShadeGuard destructive test

In destructive load testing, the ShadeGuard assembly held the panel to a test load of 3.5 kN. The full test report is included in the engineering pack.

Fire tested

All six Guard products

The complete Guard Range has been fire tested and meets the applicable fire-performance requirements for Australian scaffold containment.

The pull-out result measures the shared panel-to-track connection; the destructive-load result relates specifically to the tested ShadeGuard assembly. The engineering pack provides the test methods, configurations and results to support project-specific scaffold and containment design.

Fire tested across the Guard Range.

All six Guard products have undergone fire testing and comply with the applicable fire-performance requirements of AS 1576.7 (Int):2021 — Scaffolding, Part 7: Safe use of encapsulation on scaffolding.

Supporting fire-test documentation is available with the engineering information for your selected Guard product.

A complete approach to scaffold containment.

ScaffCover's patent-pending, modular, off-the-shelf containment system is the first of its kind globally. It brings track, purpose-designed components and the Guard Range together in one coordinated platform, giving scaffolders, contractors and project teams a complete approach to containment across a range of applications.

More than track attached to scaffold.

Keder track has been used on scaffolds before. What makes ScaffCover different is the complete system around it: a coordinated range of track, components and purpose-built containment panels, with defined roles and connections.

As ScaffCover launches in each market, the aim is to make that system available as an off-the-shelf product range. Project teams can select and configure repeatable components to suit the application, rather than develop a one-off containment arrangement for every job.

The system is intended to work within established scaffold design and engineering workflows, using existing design software and engineering methods to plan the configuration and assess project requirements. Like the scaffold supporting it, containment can then be approached as a system to be engineered, installed, inspected and maintained.

This does not replace project-specific engineering. It provides a consistent product platform on which that work can be based, with the selected panels, connections, supporting scaffold and applicable local requirements considered together.

Compliance is part of the work.

We take compliance seriously. Testing, technical documentation and clearly defined applications are central to how we develop and communicate the ScaffCover system. We distinguish between what has been tested, the conditions of that testing, and what needs to be assessed for an individual project.

For projects in different markets, the applicable local requirements, selected product and proposed configuration need to be considered together. Our Engineering page sets out the available test evidence, with supporting documentation available on request to inform specification and project review.
